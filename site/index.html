Works with Claude Code, Codex, Cursor and any agent that can run shell commands. Free and open source.

Feature tour: Assign a task to a teammate

✓ Passed · 4 steps · 31s · recorded at the PR's head

Steps

    How it works

    1. The agent writes a Playwright test in .tours/<feature>.tour.ts.
    2. pro-tour run records it, with a cursor, real typing and a notice for each step and check.
    3. pro-tour publish posts it on the PR.

    No API key, no CI.

    Setup

    Paste this to your coding agent, in your app's repository:

    Set up Pro Tour in this repository, so you can record a video tour of each change you make and post it on its pull request.

1. Install its latest release as a dev dependency with this project's package manager:
   pnpm add -D github:nishilfaldu/pro-tour#v0.1.0
   or npm i -D github:nishilfaldu/pro-tour#v0.1.0
   (Without #v0.1.0, it installs the latest commit on main instead.)
2. Through the package runner (pnpm exec or npx), run:
   pro-tour install-browser
   pro-tour init
   pro-tour doctor
   Fix what doctor reports, or tell me what you could not fix.
3. Commit what changed.
4. Read node_modules/pro-tour/docs/feature-tours.md. Then record a short tour of something already in the app, to check that it works, and tell me where the video is.

    Or by hand:

    pnpm add -D github:nishilfaldu/pro-tour#v0.1.0   # or no #v0.1.0 for the latest commit
pnpm exec pro-tour install-browser
pnpm exec pro-tour init   # commit what it writes

    Needs Node 22.18+, ffmpeg and gh. Check with pro-tour doctor.
