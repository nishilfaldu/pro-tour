pro-tour

github

Coding agents attach a video of the change to the pull request, with a checklist of what the video shows. You review by watching instead of checking out the branch.

This is the comment Codex left on a PR after being asked only to open it:

pro-tour commented

Feature tour: Assignee filter

Passed: 7/7 steps · 46s video

What this PR does

    How it works

    1. The agent finishes a change you can see in the app.
    2. It writes .tours/<feature>.tour.ts: the behaviors, then a step that shows each one.
    3. pro-tour run plays it in a browser and records it. A step only passes if its checks see something change, so the video can't just show a page that was already there.
    4. pro-tour publish posts the video and checklist on the PR. A failed tour isn't posted.

    No API key or CI. It runs on the agent you already use (Claude Code, Codex, Cursor) and your gh login.

    Setup

    pnpm add -D github:nishilfaldu/pro-tour
pnpm exec playwright install --with-deps chromium
pnpm exec pro-tour init   # installs the skill agents read

    Commit what init writes. Node 22.18+, ffmpeg and gh are needed; pro-tour doctor checks them.
